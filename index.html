Step 5

Export

Your atlas is ready. Download data exports or save the printable atlas as an HTML file you can convert to PDF using your browser's print dialog.

To save as PDF: In the atlas tab, press Ctrl+P (or ⌘P on Mac) → set orientation to Landscape → enable Background graphics → Save as PDF.
