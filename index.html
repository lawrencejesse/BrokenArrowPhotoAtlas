Photo EXIF Data Extractor

Select a folder of images to extract EXIF data and export it to CSV or GeoJSON

Instructions

  1. Choose files - browse to the folder of photos that you want to include and select upload when you are in the folder with the photos.
  2. Copy and paste the file path from the Windows Explorer address bar and paste it into the dialogue box.
  3. Click Extract EXIF Data.
  4. Choose to download the data as a CSV or GeoJSON file.

Note: The GeoJSON file is recommended as it loads into QGIS nicely and is an editable file, so the user can add comments, delete certain photos, etc.
