Short product description:

Photo Log Atlas Builder turns geotagged drone or field photos into a printable map-based photo log. It starts from the existing WebExifExtractor app, keeps EXIF extraction in the browser, adds editable comments/settings, and generates a printable HTML atlas with one photo and one satellite map per page.

Core build instruction:

Start by duplicating the existing WebExifExtractor Replit app. Add the atlas workflow there rather than starting from scratch.
